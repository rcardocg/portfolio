# Portfolio

Portafolio profesional de Ricardo Caballeros, Ingeniero en Sistemas. La página presenta una tarjeta de presentación de estilo editorial clásico (tipografía Bodoni Moda, paleta marfil, sin elementos decorativos) centrada en pantalla, con un fondo animado sutil de cuadrícula (`ShapeGrid`, de React Bits) detrás del contenido. El sitio es completamente responsive y los datos de perfil viven en `data/profile.ts`.
